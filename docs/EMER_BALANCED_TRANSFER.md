# 任务平衡训练：探索性后续实验

原用户留出实验完整保存，平均收益+1.22%，关注守护失败。诊断见[报告](../reports/emer-user-cv-tradeoffs-v1/README.md)。已有36个Jev候选都至少有一个内层单项超过0.005下降上限，不能靠简单重选一个候选解决全部约束。

本轮检验一个具体假设：原后验监督把反馈位相加，而评价平均的是各目标条件NDCG；稀疏目标在两者中的相对贡献可能不一致。频率和单信号AUC不能证明因果，因此必须进行对照实验。

## 对照及冻结规则

- 使用原三折、原训练专属标准化及真实Jev分数。两组同样从该折该种子原EMER初始化。将两组的28个Jev输入列权重归零，使初始预测与原EMER完全一致；之后仅Jev输入开关不同。
- 两组同时把“反馈总和”的后验损失替换为七目标分别计算的配对损失，以训练集上该目标可监督列表的加权比例归一化。原行为先验和动态优势权重保留。
- 相同固定学习率0.0003、先验系数0.25、15轮、batch32；三折×三种子×两组，共18次拟合，不搜索新网格。
- 内层选模同时检查七目标相对原EMER的0.005绝对退化守护，再最大化六正向均值。初始原EMER为可行备选，失败的epoch不得替换已选模型；平分保留更早轮次。
- 全部18次完成并冻结选择后再计算外层结果。完整报告回退到原EMER的情况，不隐藏零增益。

主比较是“相同任务平衡训练下的EMER＋Jev vs EMER”；同时比较“任务平衡EMER＋Jev vs 原EMER”。两项比较都沿用原平均收益和七目标守护。不能把共享损失修改的收益冒充Jev增量，也不能只选一个有利比较宣布成功。

配置：[emer_balanced_transfer_v1.json](../configs/emer_balanced_transfer_v1.json)。实现及五项相关测试已通过，真实输入、原EMER检查点和源码哈希已冻结。18次训练已启动，全部完成后自动审计、评价、独立重放和生成报告。
