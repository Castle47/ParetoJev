# 回退到匹配对照：独立记录的策略实验

前两轮使用原EMER作为两个训练分支的共同初始化和退化参考。但混合训练中，fold1/seed17与fold2/seed29的无Jev分支选中了改进模型，Jev分支却回退到旧初始化。因此部署一个未选中Jev模型的分支时，反而可能丢弃已经取得的无Jev改进。

新策略只用冻结的内层指标：候选Jev模型的六目标均值必须严格优于同配方当前无Jev模型，且相对当前无Jev模型和原初始化都满足原七目标0.005守护。否则直接使用当前匹配无Jev检查点，预测完全相同，增量记为零。

这是一项新选择/部署策略，不改写此前注册的实验。对完整任务平衡与固定50/50两种配方同时应用；没有重训、系数搜索或种子移除。全部18个“折×种子”决策先冻结，再审计和计算任何新外层指标。两种配方分别保留4/9和5/9个Jev模型槽位，其余使用匹配对照。

配置：`configs/emer_matched_fallback_v1.json`。脚本：`scripts/run_emer_matched_fallback.py`，阶段prepare/audit/evaluate/replay/report。外接盘输出为`emer-jev-scale-v3/matched-fallback-v1`。原三轮结果和源码哈希均保留。

两个策略测试覆盖：仅胜过旧初始化不足以启用Jev、均值平分回退、所有目标相对两个参考均需过守护，以及缺失/非有限指标拒绝。审计会重新加载所有原检查点重算内层指标，核对决策与路由；随后独立进程重放全部外层预测和指标。

此前外层结果已经打开，本策略依然是探索性评估。即使筛查条件通过，也不自动代表独立确认、严格每目标总体占优或线上业务提升。所有外层折、种子、退化与零增益必须完整报告。65元预算不变，无新付费GPU或Jev请求；Apr23–25队列未进入本轮。
