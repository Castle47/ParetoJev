# 固定50/50后验：探索性修正

完整任务平衡实验的同配方Jev增量为+1.63%，全部单项目标守护通过，但种子29全部回退，严格的每种子正收益条件失败。原结果保持原样。

[内层轨迹诊断](../reports/emer-balanced-fallback-diagnosis/README.md)显示：种子29的Jev模型45/45轮平均分改善，却没有任何轮次同时通过七目标守护；前两折持续触发长看守护，第三折持续触发评论守护。因此不能把它解释为未训练或漏选检查点。

本轮只检验一个修正：后验损失固定为50%原EMER反馈总和配对损失＋50%条件任务平衡配对损失。这个固定中点用于检验完整替换是否取舍过大；不搜索系数。两组采用同一配方，其余初始化、三折、三种子、15轮、学习率0.0003、先验系数0.25、参数量43,345、七项守护、epoch0回退和18次完整预算全部保持一致。

仍要求“混合后验EMER＋Jev vs 混合后验EMER”以及“混合后验EMER＋Jev vs 原EMER”都通过原条件。无Jev训练方法本身的收益单独报告。不得移除种子29、将零收益写成正收益或放宽退化上限。

配置：`configs/emer_blended_transfer_v1.json`。驱动：`scripts/run_emer_blended_transfer.py`。原完整平衡驱动保持原字节和注册哈希，通用初始化、守护和评价函数复用；新训练循环单独保存以维持旧实验的精确重放。全18次完成后自动审计、评价并独立重放。

该修正是在此前外层结果被检查之后提出的，后续结果依然是探索性证据，不能称为独立确认或线上提升。仅使用已采集的真实Jev数据；无新GPU/API费用，65元上限保持不变。Apr23–25独立队列仍不进入本轮。
