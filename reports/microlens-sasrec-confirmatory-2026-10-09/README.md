# 固定 20% Jev 融合的新评价用户确认

本轮检验此前开发结果能否在 **700 名从未参与评价的用户** 上复现。
注册与实现已在训练、Jev 采集和测试指标计算之前提交为 `8a4b708`。
当前阶段的结果以本目录机器可读报告和后续执行记录为准；登记目标不代表已达标。

## 冻结规则

- 排除此前 400 名开发用户及 1,000 名 checkpoint 验证用户后，用 seed 20261011
  选定 700 名新评价用户。固定每人 5 条历史、1 个下一条观看正例和 19 个时间窗口候选。
- 当前 SASRec 与 item-CF 的训练都排除全部 2,100 名用户，剩余 57,145 名训练用户。
  SASRec 从随机初始化重训，不复用旧 checkpoint。
- 沿用开发阶段选出的结构、学习率 0.001 与固定第 15 轮；旧的 1,000 名验证用户仅作
  诊断，不能改变本轮训练轮数、方法或权重。
- 主比较：SASRec + 20% Jev 对比 SASRec；对比 SASRec + 20% MiniLM。
  权重指用户内平均名次融合，第二信号占 20%，不是概率校准或模型参数融合。
- 复用固定版本 MiniLM 的标题向量、同样的 5 条历史和最大余弦相似度。
- Jev 使用相同 AutoTrust JEV-27B 版本与逐候选 Noul(click) 提问。
  准备 14,000 个真实决策，一次一个请求、相邻请求启动至少间隔一秒。
- 请求尝试总预算跨进程累计为 14,000；发送前持久记录。失败、超时或被中断的
  请求也占预算，没有后台重试。模型版本变化、网络错误或并发写入均停止采集。
  预算耗尽但分数不齐时不得降低样本量或给出完整验证结论。
- 收齐所有用户、核对每个分数与真实原始响应后，才允许输出测试指标。
  不按中途结果提前停止、扩样、调权重、换模型或挑选用户。

## 样本量与验收

开发集上的 Jev 融合相对 SASRec 平均 AUC 增量约 0.007895，逐用户差值标准差
约 0.06608。按正态近似和两项比较的 Bonferroni 校正，200 用户检出同等增益的
概率约 29%，700 用户约 82%。这是依赖开发效果估计的规划近似，不是成功保证，
也不是“两项同时通过”的联合功效。

主指标为 AUC，两项固定比较各用 10,000 次逐用户配对 bootstrap 的 **97.5% 双侧区间**。
只有两项区间下界均 > 0 才通过本轮确认要求。HR@5、NDCG@10 等排序指标及其
95% 区间同时报告，但属于次要结果。

本轮目标配置为 [`targets_sasrec_confirmatory.yaml`](../../configs/targets_sasrec_confirmatory.yaml)。
它确认的是一个固定单目标融合规则，不能证明 full ParetoJev 的多目标架构有效，
不能改写旧的 5% 开发 gate，也不能直接替换原 Phase A 协议下的验收结果。

## 执行与重放

在仓库根目录使用项目虚拟环境：

```bash
.venv/bin/python scripts/run_microlens_confirmatory.py train
.venv/bin/python scripts/run_microlens_confirmatory.py score
.venv/bin/python scripts/run_microlens_confirmatory.py audit
.venv/bin/python scripts/run_microlens_confirmatory.py evaluate
.venv/bin/python scripts/run_microlens_confirmatory.py replay
```

`prepare` 用于首次登记，拒绝覆盖现有注册。`train` 保护已经完成的训练报告。
`score` 按冻结的身份和逐条缓存恢复，每次运行保留独立耗时记录；原始采集成本不会
被零请求重放覆盖。`evaluate` 拒绝部分 cohort，`replay` 禁用网络并比较全部预测、
逐用户指标、区间和累计采集成本。

原始数据、prepared 数据、模型 checkpoint、MiniLM 向量和真实响应缓存是本机
忽略的大文件，源码 Git bundle 不包含它们。其路径和哈希写在
[registration.json](registration.json) 及各阶段产物中。

## 适用范围

这些用户没有参与过先前的评价，但其交互曾参与旧开发模型的训练；本轮已将他们
从当前模型训练中彻底排除并重训。这仍是同一公开数据集的回溯性用户留出，
不是全局时间留出、跨平台验证或完全新采集的数据。其他训练用户的交互时间可能
晚于测试事件。负候选是未观看物品，不是实际曝光后未点击的记录。仅运行一个训练
随机种子，统计区间条件于当前模型、候选采样和数据集。

若公共端点不可用，最小外部替代输入是这 700 名冻结用户、14,000 个候选对齐的
真实 Jev 分数，附用户/候选 ID、模型版本和请求协议溯源；不会用合成分数填补。
