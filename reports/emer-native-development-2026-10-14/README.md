# EMER＋Jev 扩大开发集比较

训练30,000组，验证6,000组（60,000候选曝光、4,253用户）。本页是被用于选模型的验证集结果，不是独立测试结果。

两臂均43,345参数、3个种子、4组配置、每组30轮；共同输入、行为模型、标签、初始化种子及选择规则相同。Jev臂增加真实信号输入，基线将同尺寸Jev输入块置零。

前六项目标为NDCG@3；最后一项为前3候选的无负反馈比例，均越高越好。点估计为三种子均值；区间为2,000次用户聚类成对bootstrap，仅描述已选模型的差异，未校正同一验证集选模带来的偏差。
