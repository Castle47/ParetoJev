原生JEV-27B仍用原AutoDL实例td89w6tsnx-ba43120e及原模型/依赖/服务源码。
CPU预检逐个核对模型文件、依赖版本、输入和协议哈希；GPU启动后再次核对服务producer身份。

每组完整保存七个目标原始响应；允许有界重试，但不替换样本、不补假分数。

本地接收完整结果后执行：

```bash
bash scripts/finish_multiobjective_confirmation.sh \
  '/Volumes/曾诚的移动硬盘/ParetoJev/kuairand-27k' \
  '<完整真实打分目录>'
```
