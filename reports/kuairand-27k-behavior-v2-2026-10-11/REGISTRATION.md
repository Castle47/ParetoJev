# 27K 行为模型第二轮开发实验（结果前注册）

目标是诊断并改善首轮的概率偏低、特征不足和过拟合。采用新增的受约束
HistGradientBoosting 多任务独立头对照，不宣称 SASRec 本身已变强，也不将
树模型作为原创架构。先建立更可靠的行为基线，再回到 Jev/ParetoJev 比较。

完整早期 136,296,576 条曝光继续作为历史来源；每用户最多 64 条训练目标，
校准/评估各 8 条，均匀无放回且使用逆抽样概率权重。训练 time_ms < 4/18 零时，
校准只使用 4/18，评估只使用 4/19（Asia/Shanghai）；保留 4/20 以后的重排数据。
4/19 已被上一轮用于开发，不能称为独立未见测试。日期字段与时间戳不完全
一致的已知限制保留，按固定 time_ms 切分，不重新标注反馈。

两组共享样本、七个原始标签、预算、训练与校准方法：

- exposure_context：请求 tab、时长、时钟和严格过去的曝光历史统计；
  包括近小时/天/周曝光量、距上次曝光间隔、最近 50 次曝光的时长、重复候选
  和场景分布。不输入历史反馈标签，不把未知反馈完成时间当作已观测。
- upload_metadata_assumed_static：另外加入候选视频的上传年龄、时长、宽高、
  比例、历史作者匹配和缺失标志。author_id/upload_dt/video_duration/
  server_width/server_height 被显式假定为上传时确定的属性；缺少可用上传日或
  上传日晚于曝光当地日时屏蔽全部这些属性。历史作者也按各自历史曝光日屏蔽。
  该规则只限制未来上传，**不能证明发布表的属性从未变更**；结果依赖静态属性
  假设。排除 visible_status、整月统计、用户快照、文本和 Jev。

历史只包含 time_ms 严格小于目标的事件，同时间戳全部排除；最近 50 次是曝光
历史，不是正反馈历史。树模型不把用户/视频/作者 ID 当作有序数值输入。
这里只检验新特征的同预算增量；与上一轮 SASRec 相比，数据量、特征和架构
都改变了，不能把差异归因于某一种架构优越。

固定 64 棵树/任务、15 叶、深度最多 4、叶样本至少 500、学习率 0.1、63 bins。
L2 = 20*p_train*(1-p_train)，以同一训练目标的加权发生率确定，不使用评估标签。
训练权重归一化到均值 1；不进行类别重加权。无 early stopping、无标签驱动
搜索或评估集选模型。七个目标独立训练，非 MMoE；此对照先验证非序列特征价值。

每任务在 4/18 单独拟合正斜率 Platt 校准，在 4/19 比较 raw/calibrated 指标。
斜率/截距范围、正则与优化次数均冻结于 JSON 配置；失败须报告，不能偷偷
回退或放宽门槛。校准保持单任务排序，不把校准当作新的排序提升。

发生率基线只从相同训练样本估计，按 tab 基线加入 100 个全局先验伪曝光。
逐任务报告加权 ROC-AUC、PR-AUC、log loss、Brier、ECE、发生率/平均预测。
开发门槛比首轮更严格：七目标各 >=20 个评估阳性、AUC>0.5，且校准后 log loss
和 Brier 都优于按 tab 发生率。只有全部任务通过才标记本轮开发就绪，不能
等同于原项目研究目标完成。保留所有失败项，不增加轮数直到“显著”。

对 metadata/context 的校准后 log loss 差异做 1,000 次用户簇 bootstrap；
区间是探索性、条件于已训练模型、未做多重校正，不是确认性显著性检验。
保存字段清单、缺失/未来上传屏蔽统计、源文件与数组哈希、模型、校准器和预测。
独立进程重载应逐元素复现预测与指标。零 Jev 调用，不消耗后期测试数据。
