# EMER＋Jev：三折用户留出的回溯验证

使用既有36,000组真实分数、12,606名用户，未新增Jev请求或付费GPU。每组预测只来自该用户未参与训练和内层选模的模型；两臂共72次从头拟合。

**本报告是已探索数据上的回溯性、按用户分组的样本外评价，不是新日期独立测试。**用户此前可能参与过Apr19之前的冻结行为模型；用户隔离约束针对本轮重排器训练与选模。

上述条件仅为回溯证据筛查，不自动等价于完整项目成功。各折训练集相互重叠，不能把3折或9个种子-折组合当成独立实验重复。条件区间没有包含重新训练整套算法的全部不确定性，也未消除既往探索该数据的影响。

方法依据：[Cawley与Talbot：选模过拟合与评价偏差](https://www.jmlr.org/beta/papers/v11/cawley10a.html)、[Bengio与Grandvalet：K折交叉验证方差的限制](https://www.jmlr.org/papers/v5/grandvalet04a.html)。

全部用户划分由固定哈希决定，不依据标签或结果重分；标准化只拟合内层训练候选。每个外层折、每个种子和每个方法都有相同四组配置、每组30轮；只用内层验证集选模型。全部72次拟合和选择冻结后才计算折外指标。

原Apr23-25的5万组确认数据未参与本轮，原模型和此前结果未改写。模型来源仍为固定原生JEV-27B，七目标树行为预测在Apr19之前拟合并冻结。

全部预测、指标和区间在独立进程重放。证据：evaluation.json、selection.json、preparation.json、registration.json和replay.json。

数据及全部三折选模审计记录随报告保存：data_audit.json、fold-0/1/2-selection-audit.json。
