# 有基线保底的有限修正：Jev与行为信号同容量对照

**2026-10-14；开发实验，未开放独立测试。** 固定原EMER模型，分别用行为信号或真实Jev信号训练有限修正。两组各7个系数、相同3个正则强度、同样的训练/验证规则；每候选修正幅度≤原列表分数标准差的25%。

## 数据、训练和选模

- 30,000组训练、6,000组验证（60,000验证曝光，4,253验证用户），全为已准备的真实开发数据。
- 原43,345参数的EMER完全冻结，两修正组各新增7个系数；3种子×3正则×2组，共18次小模型拟合。
- 输入是七项信号的列表内中心化排名，负反馈方向取反；训练只优化训练集加权长看成对逻辑损失。
- 验证选模以长看最大化为准；长看和六正向均值不能低于原EMER，点击/无负反馈绝对下降最多0.005。
- 零修正先进入候选且并列优先，不满足约束时回退原EMER；系数范围[−4,4]，幅度上限和搜索空间在训练前冻结。
- 这些约束只保证被选候选在本验证集的点估计，不是总体、置信区间或线上无损保证。

协议提交：`ce73612`；完整输入校验及守护测试提交：`cbe4406`，均先于本轮训练结果。

## 结论与下一步

本轮没有达到进入新测试规划的开发条件。Jev有限修正未同时优于原EMER和同容量行为修正，因此不能把微小的长看点估计上涨归因为有价值的Jev增量。

不启动5万组独立测试，不新增GPU预算，不再扩大本轮搜索空间。若继续，应先核查现有Jev输入的信息充分性和目标相关性，再提出信号改进实验；不以不断微调融合系数寻找验证集正结果。

这一结论仅限本数据、当前文本Jev信号和已登记的有限修正框架；不能推论所有Jev应用都无效。
