## 输入到位后的一条命令

在仓库根目录执行：

```bash
bash scripts/finish_emer_routed_confirmation.sh \
  '/Volumes/曾诚的移动硬盘/ParetoJev/kuairand-27k' \
  '<完整真实打分目录>'
```

它依次核验固定登记与原始响应、构建公共数值输入、使用模型包内部三折编码器推理、计算三组完整七目标对照、独立进程重放，最后生成`reports/emer-routed-confirmation-v1/README.md`。标签不会进入模型推理输入；缺少任何真实评分时，不提前输出基线测试指标。

模型和协议在该独立队列的性能计算之前冻结。主比较及原EMER参考比较都沿用平均收益、每种子/每路由组正收益和七项目标点估计守护；不因结果改变样本量、模型或门槛。原评分包配置保持原字节，用于验证producer和请求身份；新协议单独冻结候选模型、路由、评价规则。
