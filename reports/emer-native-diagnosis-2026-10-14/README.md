# EMER＋Jev 开发集诊断：尚无稳定长看增益证据

2026-10-14。全部24个既有checkpoint重新推理，并逐项重算对应训练收据中的验证指标。无新增训练、Jev请求或付费GPU；仅用6000组开发验证数据。原先的主比较与选模结果不改写。

## 主要判断

1. 原主比较长看+2.00%对配置选择敏感。四组同超参数比较中，三组长看点估计为负；唯一正向组的差值区间跨零。没有发现同配置下稳定可信的长看提升。
2. 当前选模最大化六正向目标的平均NDCG，而项目主指标是长看。这两者可能发生权衡；本次原规则得到的结果是真实的，但不能被解读为Jev在各种配置下都改善长看。
3. Jev单独按长看排序弱于行为预测，不能因为存在纠错案例就推断它能带来净收益。负反馈识别出现更积极的开发迹象，仍不等于融合后或线上收益。
4. 固定分组均未解决跨种子不稳定问题。暂不启动新的5万组独立测试打分。

所有区间均未校正选模及多重诊断比较，仅作探索描述；不能拿本报告重新挑一个有利配置作为新的确认结果。

### 为什么原主比较平均长看能升2%？

原选模下，seed7的EMER选择学习率0.001、先验系数1.0，长看为0.394230；EMER＋Jev选择0.0003、0.25，长看为0.422263。然而，既有EMER在同一个0.0003、0.25配置下已经达到0.422067，对应Jev差值仅+0.000196。seed17/29原主比较长看均下降。

这解释了结果对选模的敏感性，不否认原来的等预算选择流程，也不是把事后选出的新基线替换原主比较。seed7基线被选中的六目标均值只比其0.0003/0.25配置高约0.000984，长看却低约0.027837。

## 决策与下一轮边界

当前停止在开发诊断，不花费额外预算打开独立测试。下一轮应先把长看守护条件与选模规则协调好，再在训练/验证范围内检验有行为基线保底的有限Jev修正。这是待验证的开发假设，尚未实现或训练，也不能通过事后改门槛把本轮宣布为成功。

已有相同epoch的1/5/10/20/30轮验证曲线差值也完整保留在epoch_receipts中；只比较已有训练收据，不重新选择epoch，不据此断言导致不稳定的唯一原因。
